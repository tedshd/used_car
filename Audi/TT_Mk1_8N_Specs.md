# Audi TT Mk1 (8N) 技術規格百科

## 車型概述
Audi TT Mk1 (底盤代號 8N) 於 1998 年發表，其設計源自 1995 年的法蘭克福車展概念車。以「圓潤、對稱、幾何」為核心設計語言，是工業設計史上極具影響力的量產車款。

---

## ⚙️ 核心動力與驅動系統 (常見規格對比)

目前台灣市場流通的 Mk1 主要是 1.8 升四缸渦輪增壓版本：

| 規格項目 | 1.8T (180hp 版本) | 1.8T (225hp 版本) |
| :--- | :--- | :--- |
| **引擎代號** | AJQ / APP / AUQ | **APX / BAM** (體質較強) |
| **渦輪型號** | K03 / K03s | **K04** (較大出風量) |
| **變速箱** | 5速手排 / 6速 Tiptronic | **6速手排 (02M)** |
| **驅動方式** | 前輪驅動 (FWD) | **Quattro (Haldex)** |
| **中冷器** | 單側中冷 | **雙側中冷 (Dual Intercoolers)** |
| **排氣管設計** | 單邊雙出 (擠在左側) | **左右單出 (雙邊單管)** |
| **後避震結構** | 扭力樑 (FWD) | **獨立多連桿 (Quattro)** |

## 📐 基本車體數據 (Coupe 版本)
*   **軸距：** 2,422 mm (Quattro 版為 2,429 mm)
*   **車長：** 4,041 mm
*   **車寬：** 1,764 mm
*   **車高：** 1,346 mm
*   **車重：** 約 1,280 kg (180hp) / 1,475 kg (225hp Quattro)

## 🏆 S-Line 版本 vs. 一般版本 (差異解析)

S-Line 是 8N 世代後期的精裝版本 (主要出現在 2002-2006)，其核心價值在於更具侵略性的視覺感與強化的動態表現。

### 1. 外觀部分 (Exterior)
*   **前格柵：** S-Line 改為**「蜂巢狀」**水箱護罩與進氣格柵，一般版本為橫柵式。
*   **後下擾流：** 換裝了黑色蜂巢狀裝飾板。
*   **銘牌：** 車側與門檻處有專屬「S-Line」標誌。
*   **頭燈：** 部分 S-Line 版本會配備鈦合金色調的燈座內殼（非一般銀色）。

### 2. 底盤與操控 (Chassis)
*   **車身高度：** 原廠出廠即配置 **S-Line 運動化懸吊**，車高比一般版降低 **20 mm**。
*   **阻尼與彈簧：** 阻尼係數提高約 30%，彈簧硬度也同步提升，操控感更直接。
*   **防傾桿：** 升級為加粗版防傾桿，有效抑制彎道側傾。

### 3. 內裝質感 (Interior)
*   **方向盤：** 換裝**「透氣穿孔皮革」**包覆的三幅跑車方向盤，並帶有 S-Line 徽章。
*   **排檔頭：** 鋁合金排檔頭採用霧面磨砂處理。
*   **天蓬與內飾：** 標配 **「黑色頂蓬」**，營造更強的戰鬥機座艙氛圍。
*   **門檻：** 帶有髮絲紋鋁合金 S-Line 踏板。

## 🛑 鑑定師私房重點 (8N 專屬)

### 1. ESP 功能檢測 (安全核心)
*   **靜態檢查：** 開啟電門 (不發動) 時，儀表應出現「黃色三角形閃電」符號 (ESP 燈) 並隨後熄滅。若完全不亮燈，可能燈泡被拔除以掩蓋故障。
*   **手動開關：** 按下中控台的「ESP」按鈕，儀表應恆亮 ESP 燈 (代表關閉)；再次按下燈號應熄滅。
*   **診斷掃描：** 使用 VCDS 或 OBD2 掃描器，重點檢查「ABS/ESP Module (Address 03)」有無歷史故障碼。常見故障為橫向加速度感測器 (G200) 或轉向角度感測器 (G85)。
*   **動態驗證：** 在空曠、安全的溼滑路面或碎石地小幅度轉向加油，若 ESP 介入，儀表燈號應會閃爍且動力會被暫時限制。

### 2. 內裝標誌性設計
*   **鋁合金裝飾：** 大量使用真正的鋁合金（而非鍍鉻塑料），包含冷氣出風口環、排檔座圓環、油箱蓋。
*   **手套箱/置杯架：** 8N 的置杯架非常稀有且脆弱，若物件包含正廠置杯架是加分項。

### 2. 安全歷史：後鴨尾與 ESP
*   **早期事件：** 1999 年初期的 TT 並無後尾翼，但在德國高速公路發生多起高速失控事故。
*   **修正：** 隨後 Audi 召回所有 TT 並強制加裝**小型鴨尾 (Rear Spoiler)** 與 **ESP 系統**。目前市場上「無尾翼版」極為罕見且具備特殊收藏地位，但高速穩定性較差。

### 3. 變速箱系統
*   **手排：** 5MT 與 6MT 結構極其強壯，是 8N 最推薦的配置。
*   **自動/序列式：** 
    *   2003 年前為 **Tiptronic (6速手排自排)**。
    *   2003 年後部分版本引進了初代的 **DSG (DQ250)**，搭配 3.2L V6 引擎。

## 🛠️ 常見維修與保養建議
*   **機油：** 5W-40 (符合 VW 502.00/505.00 規範)。
*   **正時皮帶：** 建議每 8 萬公里更換「正時皮帶 + 水幫浦」套餐，避免皮帶斷裂導致引擎報廢。
*   **真空管路：** 1.8T 引擎室高溫，橡膠真空管與廢氣回收管 (PCV) 易脆化導致漏氣。

## 專家綜合評價
Audi TT 8N 225hp Quattro 是這代車型的「完全體」。具備 K04 渦輪、6 速手排與四驅系統，它不僅僅是一件藝術品，更是具備高性能實力的真小跑車。
