# Audi S4 / S5 (B8 / B8.5 3.0T V6 Supercharged) 技術規格與二手鑑定百科

## 車型概述

Audi S4 B8 世代（2009–2015 年生產）是奧迪極具代表性的高性能中型房車/旅行車（Sedan / Avant）。核心動力放棄了上一代 (B7) 的 4.2L V8 自然進氣，改採 **EA837 3.0 升 V6 機械增壓引擎** 配 **Quattro 四輪驅動** 與 **DL501 7速濕式 S-Tronic 變速箱**。

這款 EA837 3.0T 引擎被譽為「奧迪近年最耐用、改裝潛力最大的 V6 引擎之一」，結合親民的 3.0L 稅金，是中古性能車市場中兼具動力與實用性的熱門首選。

## 🛠️ 鑑定師與工程師維修痛點 (S4 3.0T 專屬)

### 1. 節溫器 (Thermostat) & PCV 閥老化 —— ⚠️ **最常見必做保養**
* **原理**：節溫器與 PCV 閥（廢氣回收閥）位於機械增壓器**正下方**。
* **徵狀**：節溫器咬死導致水溫過高沸騰；PCV 閥破裂導致吃機油、怠速運轉抖動。
* **建議**：只要拆下機械增壓器，**務必一次將「節溫器 + PCV 閥 + 增壓器下水管 + 冷卻液」打包更換**（連工帶料約 NT$ 2萬~3.5萬元）。

### 2. DL501 (0B5) 7速 S-Tronic 變速箱閥體 (Mechatronics)
* **原理**：DL501 內部印刷電路板與電磁閥高溫老化，導致訊號異常。
* **徵狀**：入 R 檔無反應、打檔衝擊、儀表亮「變速箱故障」警示燈並鎖檔。
* **處置**：更換閥體修復套件 / 電路板強化件（約 NT$ 3萬~5萬元）；若全套更換約 8~12 萬。B8.5 後期款故障率已顯著降低。

### 3. 水幫浦 (Water Pump) 滲漏
* **原理**：早期原廠塑膠水幫浦易龜裂漏水。
* **處置**：建議升級為最新版金屬/鋁合金水幫浦。

### 4. 前懸吊多連桿鐵套老化
* **徵狀**：過坑洞異音、高速重煞車時方向盤拉扯抖動。更換前雙 A 臂 / 多連桿鐵套套餐可恢復路感。

與昂貴且嬌貴的 S6 (4.0T V8) 或 S8 (5.2 V10) 相比，**S4 3.0T V6 是 Audi S 系列中 CP 值最高、維修最友善、改裝潛力極大的黃金車款**！僅需寫 Stage 1 晶片與直刷，馬力即可輕鬆突破 **400 hp**，是兼顧日常家庭代步與熱血樂趣的優質性能車。

## 📋 二手車實車鑑定 Check List

1. **認清 B8 前期與 B8.5 後期**：看頭燈日行燈型狀（雙 C 光條為 B8.5）、看有無電子轉向與新版方向盤。
2. **測試 DL501 變速箱**：冷車與熱車狀態下反覆打 R 檔與 D 檔，測試有無延遲、重擊感或亮燈。
3. **查驗水溫與水箱保養紀錄**：詢問賣家增壓器下方之「節溫器與 PCV 閥」是否更換過。
4. **測試 Quattro 與後差速器**：慢速大角度迴轉，聽後軸有無異音（若有選配 Sport Differential 跑車差速器需檢查保養油品）。
