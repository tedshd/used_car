# Audi TT Mk2 (8J) 技術百科

## 車型概述
第二代 Audi TT (底盤代號 8J) 於 2006 年發表，採用了 Audi 引以為傲的 **ASF (Audi Space Frame)** 鋁合金/鋼材複合車體技術，前段為鋁合金、後段為鋼材以達成絕佳的配重。

## 技術規格：2.0 TFSI (早期型)

| 項目 | 詳細規格 | 專家註解 |
| :--- | :--- | :--- |
| **引擎型號** | 2.0L EA113 TFSI | 採正時皮帶帶動，非後期 EA888 |
| **最大馬力** | 200 hp @ 5,100-6,000 rpm | 早期版本，改裝潛力極佳 |
| **最大扭力** | 28.6 kgm @ 1,800-5,000 rpm | 寬廣的扭力高原 |
| **變速箱** | 6速 S-tronic (DQ250) | 濕式雙離合器，換檔極快 |
| **驅動方式** | 前輪驅動 (FWD) | 早期 2.0T 多為前驅版本 |
| **0-100 km/h** | 約 6.4 秒 | |

## 🛑 鑑定重點：TT Mk2 (8J) 核心通病 (Critical Faults)

### 1. 機械系統 (EA113 引擎)
*   **機油消耗 (Oil Consumption)：** 雖然比後期 EA888 稍微好一點，但高里程車輛仍需檢查活塞環與廢氣回收閥 (PCV)。
*   **正時皮帶 (Timing Belt)：** EA113 為皮帶帶動，建議每 8-10 萬公里更換，否則斷裂會導致引擎報廢。
*   **高壓油泵頂筒 (Cam Follower)：** TFSI 引擎必看。若頂筒磨穿會傷及凸輪軸，維修成本極高。

### 2. S-tronic (DSG) 變速箱
*   **閥體 (Mechatronics)：** 檢查低速爬行是否有明顯抖動，或 2 檔降 1 檔是否有撞擊感。
*   **變速箱油保養：** 必須每 6 萬公里更換油液與濾網。

### 3. 車體與電系
*   **電動後撥翼：** 時速 120km/h 自動升起，低於 80km/h 收回。需測試手動按鈕是否正常。
*   **尾燈接地線不良：** 8J 的經典通病，會導致儀表顯示燈泡故障，實則為接頭熔毀。
*   **磁流液避震器 (Audi Magnetic Ride)：** 若有選配，單支更換費用高昂，需檢查是否有漏油跡象。

## 🛠️ 鑑定師選購指南 (Buying Advice)

### 1. 改裝價值的評估
*   **Prior-Design 套件：** 德國高端品牌，設計大膽。正品套件在台灣極為罕見，價值極高，但需確認是否為纖維副廠件。
*   **大尺寸輪框 (19吋)：** 提升視覺張力，但需注意是否影響路感與避震器壽命。

## 專家綜合評價
TT Mk2 (8J) 是目前性價比最高的入門跑車。它擁有了現代化的底盤技術，且外型至今依然前衛。2.0 TFSI 加上 S-tronic 是最主流的配置，好改、好維修且稅金合理。
