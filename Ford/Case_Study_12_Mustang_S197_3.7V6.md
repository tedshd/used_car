# 實案分析：2012 Ford Mustang 3.7 V6 (總代理 S197)

## 車輛基本資訊
- **年份：** 2012 (S197 小改款)
- **型號：** Ford Mustang 3.7 V6 Coupe
- **代理：** 福特六和總代理
- **參考連結：** [Facebook Marketplace 販售連結](https://www.facebook.com/marketplace/item/2075428299904136)

## 整備與改裝現況解析

### 1. 總代理優勢 (General Agent Bonus)
在台灣，2012 年式的野馬有許多是美規外匯車，這台如果是**正總代理**，具有以下價值：
- **里程真實性：** 總代理車款在原廠通常有完整的保養紀錄可查。
- **電路穩定：** 總代理車型針對台灣法規做的燈具修改較為專業，不像部分外匯車改得亂七八糟導致漏電或電腦訊號錯誤。
- **配備完整：** 通常標配 Shaker 音響系統與大型中控螢幕（若當年有選配）。

### 2. 動力系統：305 匹馬力的心臟
- **引擎：** 2012 年開始搭載的 3.7L V6 引擎，比起早期的 4.0L 更有衝勁且更省油。
- **變速箱：** 搭載 6R80 六速自排，這具變速箱非常強壯，即便後續想加裝機械增壓，這具變速箱也能承受。

### 3. 鑑定師專業風險評估 (S197 專屬)

#### ⚠️ 經典漏水檢查 (Must Check)
這台車鑑定時第一件事就是**「摸地毯」**。
- **副駕駛座地板：** 檢查地毯下方是否潮濕。S197 排水孔若堵塞，雨水會灌入損壞 **Smart Junction Box (SJB)**，這會導致車燈、雨刷或防盜系統出現靈異現象。

#### ⚠️ 底盤與操控
- **後硬軸 (Live Axle) 特性：** 這是 S197 的特色也是缺點。在不平路面過彎時，車尾會有明顯的跳動感，這不是避震壞掉，而是先天結構使然。
- **控制臂襯套：** 檢查前三角架襯套是否龜裂，這會影響轉向的精準度。

#### ⚠️ 外觀細節
- **引擎蓋氧化：** 檢查引擎蓋前緣是否有細小的氣泡，這是鋁合金引擎蓋與車漆反應的通病，修復需要整片重新噴漆。

## 專家綜合評估
2012 Mustang 3.7 是美式肌肉車最理性的一代。它有 S197 那種致敬 1960 年代的經典復古外型，卻有著現代化的動力輸出（305hp）。

**建議開價參考：**
目前 2012 年式 3.7 V6 總代理的行情約在 **55 萬 ~ 65 萬台幣** 之間。
- **高價理由：** 低里程、全原廠、總代理紀錄完整、內裝無損。
- **低價理由：** 有事故修復史、改裝不專業、內門板起泡嚴重。

**總結：**
這是一台「外觀 100 分、內裝經典、動力足夠」的街頭焦點。如果你想要那種好萊塢電影裡的野馬韻味，S197 比現在路上隨處可見的六代 (S550) 更有味道。
