# Ford Mustang (5th Gen S197 Phase II) - 3.7L V6 技術百科

## 車型概述
第五代 Ford Mustang S197 的後期改款（2011-2014）是野馬在機械結構上的「成熟期」。搭載了 3.7L Cyclone V6 引擎與來自 ZF 技術授權的 6R80 六速自排，這代車型在保有傳統肌肉車靈魂的同時，大幅提升了日常妥善率。

## 技術規格與架構

| 項目 | 詳細規格 | 專家註解 |
| :--- | :--- | :--- |
| **引擎代號** | 3.7L Cyclone (Duratec 37) | 全鋁合金、Ti-VCT、正時鏈條 |
| **馬力/扭力** | 305hp / 38.7kgm | 自然進氣效率優異 |
| **變速箱** | 6R80 6-Speed SelectShift | 源自 ZF 6HP26，可承受極高扭力 |
| **後軸結構** | 三連桿硬軸 (Solid Live Axle) | 附 Panhard Rod (潘哈桿) 橫向定位 |
| **底盤系統** | 前麥花臣 (MacPherson) | 側向支撐剛性較前期 (2005-09) 大幅提升 |

## 🛑 鑑定重點：S197 世代核心通病 (Critical Faults)

### 1. 電系與漏水 (The "SJB" Cancer)
*   **SJB (Smart Junction Box) 損毀：** 位於副駕駛座 A 柱下方。若前擋風玻璃下方的 Cowl Drain (排水孔) 被落葉堵塞，雨水會溢流進車室。
    *   **症狀：** 燈光亂閃、遙控器失效、電動窗異常、冷氣無法作動、漏電。
    *   **鑑定：** 務必翻開副駕地毯，觸摸防火牆隔音棉是否有濕氣或異味。
*   **Shaker 音響放大器漏電：** 原廠擴大機常有休眠電流過大問題，導致停放 2-3 天後電瓶沒電。

### 2. 引擎機械系統 (Engine & Drivetrain)
*   **內部水幫浦漏水：** 3.7L V6 的水幫浦設計於前端，壽命約 12-15 萬公里。
    *   **鑑定：** 檢查皮帶盤後方及油底殼邊緣是否有粉紅色 (Motorcraft Orange) 結晶體。
*   **EVAP Purge Valve (活性碳罐電磁閥)：** 故障率極高。
    *   **症狀：** 加完油後難以啟動、怠速不穩、亮 CEL (P0443 / P0456)。
*   **6R80 Lead Frame (變速箱電子板)：** 內含轉速感測器，損壞時會導致行駛中突然降至一檔或跳 N 檔。
    *   **鑑定：** 檢查變速箱插頭處有無油漬滲透進電子接頭。

### 3. 底盤與車體結構
*   **引擎蓋鋁氧化 (Hood Corrosion)：** 鋁製引擎蓋前緣因鋁鐵異質金屬電化腐蝕，容易產生泡狀白斑。此為製程問題，重噴漆後仍可能復發。
*   **潘哈桿 (Panhard Rod) 異音：** 後硬軸在激烈操駕或降低車身後，橡膠襯套容易撕裂，導致後軸產生橫向位移與敲擊聲。
*   **上連桿 (Upper Control Arm) 襯套：** 位於後軸上方，負責抵銷扭力，高里程車輛此處常見撕裂，造成起步或收油時有震動感。

## 🛠️ 深度保養與升級建議

### 1. 保養規範 (Maintenance Standard)
*   **機油：** 5W-20 或 5W-30 (全合成)，容量約 5.7L。
*   **冷卻水：** **嚴禁使用綠色冷卻水**。必須使用 Motorcraft Orange (VC-3) 或符合 WSS-M2C949-A 規範的長效型冷卻水。
*   **後差速器油：** 75W-140 (合成)。若具備 LSD (限滑差速器)，必須額外添加 4oz 的 Friction Modifier (摩擦改進劑)。

### 2. 鑑定師私房建議 (Expert Tips)
*   **冷氣鼓風機：** S197 鼓風機電阻容易燒毀，檢查風量 1-4 段是否皆正常。
*   **燃油系統：** 美規車型對油品較敏感，建議在台灣定期使用高品質燃油系統清潔劑，避免 Ti-VCT 電磁閥卡滯。
*   **底盤升級：** 若要改善「過彎像開船」的問題，優先建議更換「加粗防傾桿」與「後軸潘哈桿 (可調式)」，能讓 S197 在彎道中的後軸彈跳感顯著減輕。

## 專家綜合評價
S197 Phase II (2011-2014) 是目前台灣野馬市場中 CP 值最高的世代。雖然存在漏水與電系通病，但只要掌握 **「通排水、換水幫浦、重做 SJB 防護」** 三大要領，這是一台非常耐操且極具風格的肌肉車。
