# Volkswagen Golf Mk2 (Type 19E/1G) 技術分析與選購指南

## 1. 車型背景
Golf Mk2 於 1983 年至 1992 年間生產，是福斯歷史上最成功的車型之一。相比 Mk1，其軸距更長、車身更寬，改善了空間表現與行路質感。在台灣市場，Mk2 是經典老車玩家的入門首選，結構簡單且零件流通性極高。

## 2. 技術規格與重點
*   **引擎配置：** 
    *   常見為 1.6L、1.8L 8V 自然進氣引擎（單點噴射或化油器）。
    *   高性能版 1.8L 16V (GTI) 具備更高轉速表現。
    *   末期 G60 機械增壓版本（稀有）。
*   **底盤結構：** 
    *   前：麥花臣支柱式附防傾桿。
    *   後：扭力樑式半獨立懸吊。
*   **傳動系統：** 
    *   3 速自排（動力流失大且耐用度一般）。
    *   5 速手排（代號 020，操作手感直接但換檔機構易損）。

## 3. 常見通病與維修要點
*   **車體鏽蝕：** 
    *   電瓶底座、加油口內側、前後擋風玻璃下緣、側裙內部。
*   **冷卻系統：** 
    *   副水箱、三通管路、水泵浦為消耗品，需注意水溫。
*   **電路系統：** 
    *   早期車型電路保護不足，需注意保險絲盒、繼電器與儀表板焊點脫落（導致水溫、油量表失效）。
*   **內裝天蓬：** 
    *   福斯通病，環保材質天蓬易塌陷，內門板泡棉老化。

## 4. 升級與改裝建議
*   **動力升級：** 
    *   常見移植 Golf Mk3 ABF 引擎 (2.0 16V) 或 Vento/Golf Mk4 1.8T 引擎。
    *   高端玩家會選擇 VR6 引擎，但需注意重量增加對轉向性能的影響。
*   **底盤優化：** 
    *   更換強化襯套（如 Powerflex）能顯著改善路感。
    *   避震器可選用 KW 或 BC 等品牌，確保低趴效果的同時兼顧路感。
*   **外觀流用：** 
    *   1990 年前的「小保桿」經典優雅；1990 年後的「大保桿」充滿現代運動感。

## 5. 二手市場行情分析
*   **一般代步等級 (5-10萬)：** 通常車況堪憂，需大筆預防性維修資金。
*   **玩家整理等級 (12-18萬)：** 車況穩定，已有基本維修紀錄或基礎外觀整理。
*   **收藏/深度改裝等級 (20-35萬)：** 包含完整烤漆、內裝翻新、或完成動力移植（如 ABF 或 1.8T），且具備合法文件。
